# SafariMarkdown

A Safari extension for macOS and iOS that detects Markdown files and shows them as rendered, GitHub-styled pages instead of raw text.

- GitHub Flavored Markdown: tables, task lists, strikethrough, autolinks
- Syntax highlighting for fenced code blocks
- Light and dark mode that follow the system setting
- Raw/Rendered toggle in the top-right corner
- Heading anchors, so links like `README.md#install` jump to the right section
- YAML front matter shown as a collapsible block
- Rendered HTML is sanitized with DOMPurify, so scripts embedded in a Markdown file don't run

## How it works

| File | Role |
| --- | --- |
| `WebExtension/detect.js` | Small content script that runs on every page. It only acts when the page is a plain-text document Safari is displaying in a single `<pre>`, and either the response is `text/markdown` or the URL ends in `.md`, `.markdown`, or a similar extension. |
| `WebExtension/background.js` | When `detect.js` finds a Markdown page, injects the renderer and its libraries into that tab only. Other pages never load them. |
| `WebExtension/render.js` | Parses with marked, sanitizes with DOMPurify, highlights with highlight.js, and swaps the result into the page. |
| `WebExtension/render.css` | Page layout, the Raw/Rendered toggle, and anchors. Typography comes from `vendor/github-markdown.css`. |
| `Markdown Viewer/` | Xcode project generated by `safari-web-extension-converter`. It references `WebExtension/` in place, so edits there are picked up by the next build. |

## Building and enabling

1. Open `Markdown Viewer/Markdown Viewer.xcodeproj` in Xcode.
2. Select your team under Signing & Capabilities for all four targets.
3. Run the **Markdown Viewer (macOS)** or **Markdown Viewer (iOS)** scheme.

**macOS:** For an unsigned debug build, enable Safari ▸ Settings ▸ Advanced ▸ "Show features for web developers". Then turn on Develop ▸ "Allow Unsigned Extensions". Enable **Markdown Viewer** in Safari ▸ Settings ▸ Extensions and allow it on all websites.

**iOS:** Go to Settings ▸ Apps ▸ Safari ▸ Extensions ▸ Markdown Viewer, turn it on, and allow it on all websites.

To try it, open any raw Markdown URL, such as a `raw.githubusercontent.com/.../README.md` link.

## Limitations

- **Local files (`file://`)**: Safari doesn't run web extensions on local files, so this only works for Markdown served over HTTP(S).
- **Downloaded instead of shown**: if a server sends a content type that makes Safari download the file instead of displaying it, the extension never sees the page.
- **Strict servers**: some hosts send a restrictive Content-Security-Policy. For example, `raw.githubusercontent.com` uses `default-src 'none'`, which blocks images embedded in the Markdown. Text, styling, and code highlighting still work.
